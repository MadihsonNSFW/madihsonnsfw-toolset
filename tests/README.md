# Toolset test suites (the full-app regression)

Started as the Anim Layers regression; since **2026-08-02** it covers the
whole app — every module, one command (the suite and check totals live in
`..\HANDOFF.md`'s CURRENT STATE block, which is the only place they are
maintained):

```powershell
powershell -ExecutionPolicy Bypass -File tests\run_all.ps1
```

Prints a line per suite and a total. Exit 0 = everything green.

**Nothing here touches your work.** The Blender suites launch a separate
`blender.exe -b --factory-startup` and build their own throwaway scenes; they
never see your open .blend. The app suites run offscreen against a stub
bridge; the Render Queue suite redirects `data_dir` to a temp folder (real
`render_queue\` state untouched), the vid-cache suite redirects `CACHE_ROOT`,
and the settings suite redirects `config.CONFIG_PATH`.

Each Blender suite loads `blender_addon\madi_anim_library\core.py` directly
by path (importlib), so it tests the code **on disk** — no reinstall needed
between edits and a test run.
